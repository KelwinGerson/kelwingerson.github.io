Privacy Policy

Last updated: November 12, 2026

What this app is

Health MCP is a personal tool used only by its owner to access his own Google Health data. It is not distributed to or used by anyone else.

Data accessed

With the user's explicit OAuth consent, the app reads Google Health data such as sleep, activity, heart rate, body measurements and nutrition.

How data is used

Data is used only to display and analyse the owner's own health information on his own devices. It is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens are stored locally on the owner's computer. No data is stored on any server operated by this app.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
